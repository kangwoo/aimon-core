# Reference notes for resource-demo

Guidance for filling in the report template:

- Keep the **Summary** to 2–3 sentences focused on the given topic.
- The **Details** section must contain exactly three concrete bullet points.
- Under **Script verification**, paste the script's output line verbatim — do not paraphrase it.
- If the topic is empty, use `sample` as the topic.

These notes live at `${AIMON_SKILL_DIR}/references/notes.md` and are only reachable because the
skill's directory was materialized into the workspace virtual filesystem.
