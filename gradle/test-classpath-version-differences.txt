# Versions a module's tests run on that are not the versions the module ships — every one, with why.

# The bar (#91): a module's tests run against the versions the module ships, unless the difference is a recorded
# choice. This file is the record, and `./gradlew checkTestClasspathVersions` (part of `checkAll`, so CI and the
# release gate) holds the build to it. It compares each module's runtimeClasspath with its testRuntimeClasspath and
# fails on:
#
#   - a difference that is not here;
#   - a line whose versions are no longer the ones resolved — the reason was written about the versions on the line,
#     so a bump on either side sends someone back to read it. The failure prints the line to write;
#   - a line whose difference is gone, or whose module the build does not have. Delete it.
#
# One difference per line:
#
#   <module> | <group>:<name> | <shipped version> -> <version under test> | <why it is left that way>
#
# The other answer to a difference is to remove it: aimon-cli, aimon-scheduling-quartz and aimon-knowledge-opensearch
# resolve their test classpaths consistently with runtimeClasspath (their build files say why), and so have no line.
#
# Rationale and rejected alternatives: docs/design/testing/test-classpath-shipped-versions.md (#99),
# docs/design/testing/test-classpath-version-check.md (this check, backlog D-3).
